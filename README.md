# Hey, I'm Jeffrey (AldogPlays)!

I'm interested in networking, systems administration, cybersecurity, and software development.

I like building things I can use, whether that's an Android app or a server running at home. Self-hosting has become a big part of that: fewer subscriptions, more control over my data, and a chance to understand the systems I rely on.

## Projects

**[TrailRelay](https://github.com/AldogPlays/TrailRelay)**\
A free, open-source Android app for off-road trail navigation, built with Kotlin and designed to work offline.

**[Goveon](https://github.com/AldogPlays/Goveon)**\
A privacy-focused Android app for controlling Govee lights over Bluetooth and Wi-Fi, without accounts or cloud services.

**[Homelab](https://github.com/AldogPlays/Homelab)**\
A self-hosted personal cloud running TrueNAS SCALE on repurposed hardware, providing everyday services.

**[LubeLogger-Android](https://github.com/AldogPlays/LubeLogger-Android)**\
A dedicated Android wrapper for my self-hosted LubeLogger server, where I keep vehicle maintenance, modifications, and fuel records.

**[Actual-Android](https://github.com/AldogPlays/Actual-Android)**\
A lightweight Android client for self-hosted Actual Budget, built with Kotlin and GeckoView.

**[Wiremix fork](https://github.com/AldogPlays/wiremix)**\
A personal UI adaptation of the PipeWire terminal mixer, with a five-section layout and Nix packaging.

The [TrailRelay community catalog](https://github.com/AldogPlays/TrailRelay-Trails) holds the GPX data used by TrailRelay.
